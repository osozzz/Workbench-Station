PRIVACY / PRIVACIDAD

Workbench Station has no account, no telemetry and no server of its own. Your reports and settings stay on this PC.
- Once a day the app asks GitHub for its latest version. Turn it off in Settings > Check for updates automatically.
- During an audit it asks public sources (WinGet, nodejs.org, npm, PyPI, GitHub and others) for the latest version of each tool. Nothing about you or this PC is sent.
Full policy: https://github.com/osozzz/Workbench-Station/blob/main/PRIVACY.md

Workbench Station no tiene cuentas, ni telemetría, ni servidor propio. Tus reportes y ajustes se quedan en este PC.
- Una vez al día, la app le pregunta a GitHub cuál es su última versión. Puedes apagarlo en Ajustes > Buscar actualizaciones automáticamente.
- Durante una auditoría, consulta fuentes públicas (WinGet, nodejs.org, npm, PyPI, GitHub y otras) para saber la última versión de cada herramienta. No se envía nada sobre ti ni sobre este PC.
Política completa: https://github.com/osozzz/Workbench-Station/blob/main/PRIVACY.md
